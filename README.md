# Skills

A collection of personal skills I use when working with agents.

## Available skills

- [`refactoring-ui`](./refactoring-ui/): Audit and improve an existing interface's hierarchy, spacing, typography, color, depth, and image treatment.
- [`write-user-docs`](./skills/write-user-docs/): Write and revise user-facing documentation for software libraries, APIs, CLIs, and developer tools.

## Install

```sh
npx skills add https://github.com/taylorbryant/skills
```

```sh
bunx skills add https://github.com/taylorbryant/skills
```
